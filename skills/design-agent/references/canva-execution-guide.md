# Canva Execution Guide — Design Agent Reference

Practical tips for executing each asset type in Canva Free. Include the relevant section in the brief when appropriate.

---

## General Canva Free Tips

- Start from a blank canvas or a free template — filter by "Free" in template search
- Elements panel → search for icons by keyword → filter "Free"
- Upload the presenter photo once → it stays in your uploads forever
- Use the "Brand Kit" section (free tier has limited features) — set your hex colors manually each time
- Group elements (Ctrl+G / Cmd+G) before moving them
- Export: PNG for web, JPG for email headers (smaller file size)
- Use "Magic Resize" only if on Pro — on Free, duplicate and resize manually

## Opt-in / Landing Page Hero

**Step-by-step:**
1. Create custom size: 1920x800px
2. Background: solid color (primary brand color) OR search Canva photos for "[niche] abstract background" → filter Free
3. Add a rectangle shape covering the bottom 30% — white or light color — this is the text zone
4. Place headline text: large, bold, high contrast
5. Add subheadline below in smaller size
6. Draw a rectangle for CTA button → round corners (corner radius: 50px for pill shape)
7. Add CTA text inside button
8. Optional: drag presenter PNG (transparent background) to the right side — resize to 60% of canvas height
9. Export PNG at 1920x800

**Mobile crop (800x800):**
- Duplicate the canvas
- Resize to 800x800
- Reposition elements for square layout
- Remove presenter image if it clashes

## Lead Magnet Cover

**Step-by-step:**
1. Search templates: "ebook cover" → filter Free
2. Pick a minimal template — delete all default images
3. Replace title with exact lead magnet title text
4. Replace author with name
5. Add brand color as accent strip (bottom 15% of cover)
6. Upload logo or type brand name
7. Export PNG

**3D Mockup:**
1. In Canva, go to Elements → search "book mockup" or "ebook mockup" → filter Free
2. Some allow you to replace the cover — double-click to upload your cover PNG
3. If no free mockup is available: use the flat cover on a colored background with a subtle shadow (Elements → "shadow frame")
4. Export PNG 1200x900px

## YouTube Thumbnail

**Step-by-step:**
1. Create custom size: 1280x720px
2. Background: bold solid color (not too light — needs contrast on YouTube dark/light mode)
3. Add text overlay: max 6 words, use Montserrat ExtraBold or Raleway Heavy
4. Text positioning: left 60% of canvas (leave right 40% for face)
5. Add presenter photo (PNG with transparent background): place right side
6. Optional: colored shape/arrow pointing toward text
7. Check readability at small size: zoom out in browser to simulate mobile thumbnail size
8. Export JPG (smaller file, still high quality for YouTube)

**A/B Test Pairs to Always Generate:**
- Version A: Text-heavy (large text, minimal face)
- Version B: Face-forward (larger presenter image, shorter text)
- Version C: Bold background color variation

## Email Header

**Step-by-step:**
1. Create custom size: 600x200px
2. Background: brand primary color
3. Center: brand name in headline font, white text, large
4. Optional: very minimal decorative line or simple icon
5. Keep it simple — the email body carries the content
6. Export JPG (lighter file for email)

---

## VSL / Webinar Slide Deck

**Step-by-step:**
1. Search templates: "pitch deck" or "presentation" → filter Free → pick minimal style
2. Set brand colors in Elements panel for each slide
3. Title slide: headline + subheadline + presenter name
4. Section dividers: full-brand-color slide with white section title only
5. Content slides: title (top) + 1 visual element (middle) + max 3 bullet points (bottom)
6. Offer slide: headline + bullet list of what's included + CTA text
7. Do NOT crowd slides — one idea per slide

**Export options:**
- Google Slides: Share → Download as → .pptx → open in Google Slides
- PDF: Download → PDF Standard
- Video: Download → MP4 Video (if using animations)

## Color Palette Recommendations for ZoltanGero

Primary: #1A1A2E (deep navy — authority, calm)
Secondary: #E94560 (warm red/coral — energy, urgency when needed)
Accent: #F5F5F5 (off-white — clean backgrounds)
Text on dark: #FFFFFF
Text on light: #1A1A2E

Primary: #2D2D2D (near-black)
Secondary: #D4A853 (gold — premium, value)
Accent: #F8F8F0 (warm white)

Use one palette consistently per domain. Do not mix palettes across campaigns.
